# 🛡️ HypoSentinel: Smartwatch-Based Early Warning System
### ระบบเฝ้าระวังความเสี่ยงภาวะน้ำตาลต่ำผ่านสมาร์ตวอทช์แบบเรียลไทม์ (Production Prototype)

---

## 📋 ภาพรวมโครงการ (Project Overview)
**HypoSentinel** คือระบบเว็บแอปพลิเคชันแดชบอร์ดต้นแบบระดับสูง (Production-Grade Prototype) ที่ออกแบบมาเพื่อการตรวจจับสัญญาณและเฝ้าระวังภัยความเสี่ยง **ภาวะน้ำตาลในเลือดต่ำ (Hypoglycemia Risk Estimation)** ผ่านข้อมูลสัญญาณชีพทางสรีรวิทยา (Physiological Signals) ที่วัดได้จากอุปกรณ์สวมใส่อัจฉริยะ (เช่น Samsung Galaxy Watch 7 หรืออุปกรณ์ Wear OS อื่น ๆ) โดยเน้นสไตล์การออกแบบที่ล้ำสมัย หรูหรา เรียบเนียนเสมือนกระจกเหลว (Liquid Glass / Glassmorphism iOS Style)

ระบบนี้พัฒนาขึ้นเพื่อวัตถุประสงค์ในการสาธิตนวัตกรรมและเตรียมความพร้อมสำหรับการทดสอบทางคลินิก (Pre-validation Phase) ในโครงการประกวดเทคโนโลยีทางการแพทย์ระดับประเทศ

## ✨ คุณสมบัติเด่นของระบบ (Key Features)

ระบบแดชบอร์ดประกอบด้วยแถบทำงานหลัก 8 แท็บย่อยเพื่อการวิเคราะห์ข้อมูลอย่างสมบูรณ์แบบ:
1. **Overview / Live Monitor**: แผงควบคุมและสังเกตการณ์สถานะสด แสดงกราฟหัวใจของนาฬิกาจำลองแบบ SVG, คะแนนความเสี่ยงสะสม (Risk Score), และแนวโน้มสัญญาณชีพปัจจุบัน
2. **Physiological Trends**: วิเคราะห์และเปรียบเทียบสัญญาณชีพอ้างอิงย้อนหลัง (Normalized Time-Series) ร่วมกับตารางค่าเฉลี่ยส่วนบุคคล (Baseline Calibrated)
3. **Risk Engine Model**: แสดงแผนผังสถาปัตยกรรมตัวแปลงข้อมูล (Data Pipeline Flow) และฟังก์ชันคำนวณแบบป่าสุ่ม (Random Forest Decision Tree Concept - Model `HS-RF-v0.1`)
4. **Markov Risk State Transition**: โมเดลคาดการณ์ความหนาแน่นของการย้ายกลุ่มความเสี่ยงในอนาคต 15-30 นาทีล่วงหน้า ผ่านทฤษฎี Markov Chain
5. **Explainable AI (Shapley Index)**: การให้เหตุผลประกอบการเตือนภัยด้วยคุณลักษณะเด่น (Feature Contribution) อธิบายสัดส่วนของแต่ละสัญญาณชีพที่มีอิทธิพลต่อความเสี่ยง
6. **Alert History Log**: บันทึกประวัติเหตุการณ์เตือนภัยย้อนหลังอย่างละเอียด มีตัวกรองแยกประเภทและฟังก์ชันส่งออกข้อมูลเป็น CSV / PDF สำหรับแพทย์
7. **Device & Signal Quality**: แสดงผลคุณภาพของชุดข้อมูลดิบ (Completeness Index) และสัญญาณบลูทูธ พร้อมรายงาน Sync & Diagnostics Log สด
8. **Settings & Baseline**: แผงประวัติและข้อมูลส่วนบุคคลสำหรับการตั้งค่าและปรับเทียบค่าฐานเฉลี่ย (Baseline Calibration)

## 🛠️ เทคโนโลยีที่ใช้พัฒนาระบบ (Technology Stack)
แดชบอร์ดนี้ถูกพัฒนาในลักษณะ **Single Page Application (SPA)** แบบจบในไฟล์เดียว (Zero-Build-Pipeline) เพื่อให้ง่ายต่อการนำขึ้นโฮสต์บน GitHub Pages หรือเปิดใช้งานแบบออฟไลน์ได้อย่างถูกต้องและแสดงผลไม่ผิดเพี้ยน:
* **HTML5**: โครงสร้างเอกสารแบบ Semantic
* **Tailwind CSS (Play CDN)**: สำหรับการออกแบบ UI ระบบกล่องแก้วโปร่งแสง (Glassmorphism), แสงสลัวพื้นหลัง (Ambient Glowing Blobs) และการปรับแต่งสไตล์อย่างยืดหยุ่นรองรับทุกหน้าจอ (Responsive Design: Mobile, Tablet, PC)
* **Chart.js (CDN)**: ระบบพล็อตกราฟอนุกรมเวลาเปรียบเทียบและการพยากรณ์ความเสี่ยงแบบมีปฏิสัมพันธ์
* **Lucide Icons**: ชุดไอคอนแสดงผลแบบเวกเตอร์ที่คมชัด
* **Pure JavaScript (ES6+)**: ระบบควบคุมกลไกประมวลผลสถานการณ์เดโมจำลอง (Dynamic Scenario Simulator Engine)

## 🧪 ระบบจำลองสถานการณ์ทดสอบ (Scenario Simulator)
ด้านล่างของหน้าจอจะติดตั้ง **Scenario Simulator Console (แผงควบคุมการสลับเดโมจำลอง)** ซึ่งจะพับเก็บไว้เป็นค่าเริ่มต้น (Collapsed by default) เพื่อความประณีต ผู้นำเสนอผลงานสามารถเปิดแผงนี้เพื่อจำลองสภาวะต่าง ๆ ได้ทันที 8 สถานการณ์ ได้แก่:
1. **Normal Sleep**: สภาวะนอนหลับปกติ สัญญาณชีพอยู่ในเกณฑ์ปลอดภัย
2. **Watch**: สภาวะเฝ้าระวัง เริ่มมีความผันผวนของสัญญาณชีพเล็กน้อย
3. **Warning**: สัญญาณชีพบ่งชี้ความเสี่ยงสูงขึ้น (อัตราเต้นหัวใจสูง, HRV ลดลง, อุณหภูมิกายลดลง)
4. **High Risk**: สภาวะความเสี่ยงรุนแรงระดับสูง
5. **Motion Noise**: การจำลองผลขณะร่างกายเคลื่อนไหวเพื่อทดสอบระบบตัดสัญญาณรบกวน (False Alarm Suppression)
6. **Missing Data**: การจำลองสถานะข้อมูลขาดหายชั่วคราว
7. **Disconnected**: สัญญาณการสวมใส่หรือบลูทูธนาฬิกาขาดการติดต่อ
8. **Reconnected**: การกู้คืนการทำงานและรับส่งข้อมูลหลังสัญญาณหลุดโดยอัตโนมัติ

## 📂 โครงสร้างการติดตั้งและการใช้งาน (Getting Started)

เนื่องจากระบบถูกออกแบบมาให้ไม่มีการพึ่งพาระบบ Backend หรือฐานข้อมูลภายนอก (Firebase/Cloud) เพื่อให้กรรมการสามารถตรวจสอบและเข้าถึงได้ง่ายและรวดเร็ว:

### 1. การเรียกใช้งานในเครื่องโลคัล (Local Running)
ดาวน์โหลดโฟลเดอร์นี้และเปิดไฟล์ [index.html](file:///Users/coolnutmacbook/Desktop/SmartWatch-WebApp-HypoSentinel/index.html) ในเว็บเบราว์เซอร์มาตรฐานใดก็ได้ (แนะนำ Google Chrome, Safari, หรือ MS Edge)
```bash
# หรือใช้เซิร์ฟเวอร์แบบเบา ๆ ในเครื่อง
npx serve .
```

### 2. การอัปโหลดขึ้น GitHub Pages (Deployment)
คุณสามารถนำโปรเจกต์นี้ขึ้นไปเปิดใช้งานออนไลน์แบบสาธารณะบน GitHub Pages ได้ง่าย ๆ โดยการสร้าง Repository ใหม่บน GitHub จากนั้นพุชไฟล์นี้ขึ้นไป แล้วเปิดตั้งค่าที่ **Settings > Pages > Deploy from a branch > main** ลิงก์แดชบอร์ดก็จะใช้งานได้ทันทีโดยไม่มีการเพี้ยนของสไตล์ชีต
